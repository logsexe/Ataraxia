# Still 0.2.2

The feed was jumping, leaving empty gaps, and then going blank. The page script was hiding reel links inside posts and counting them while you scrolled. That fight is gone. The post counter is not applied in this build.

On a profile, file the person as a friend, an influencer, or a celebrity. On the feed, the row under the wordmark chooses which of those groups to keep. Someone you have not filed yet stays in the feed.

Reels, Explore, Shop, and Live still do not open. A reel that is already a post in the feed stays put instead of leaving a hole.

## Installation

Download Still-0.2.2.apk and open it on Android 11 or newer. Uninstall the copy you have first. This build is signed with a new test key, so it cannot update the older one in place. Uninstalling clears the login stored in the app, not the Instagram account.

This CI build is signed with a test key and debugging is disabled. It is not a production signature.
