# 0.1.7 preview: philosophy-led entry

This preview turns Ataraxia's philosophy into a native first-run journey instead of a decorative quote screen.

## Experience

1. **About 4,000 weeks** explains that an 80-year life is roughly 4,174 weeks and frames attention as how finite time is spent.
2. **Ataraxia** introduces freedom from unnecessary disturbance through attention, intention, moderation and agency.
3. **Choose with intention** lets the person begin in Focused or Balanced mode after seeing the privacy and free-software disclosure.

The journey is shown automatically once. It remains available through **Why Ataraxia?** on Home and **Philosophy and purpose** in Settings. Revisiting it may change the browsing mode but does not reset time, post counts or cooldown.

## Product boundaries

The experience must not become another engagement surface. It has no quote feed, streak, badge, guilt score, forced daily reflection or remote content. The bundled product charter rejects infinite continuation, engagement optimisation, developer advertising and payment-gated wellbeing controls.

Ataraxia remains free. It has no developer ads or analytics. Instagram still processes website activity, filtering is best effort, and limits only apply inside Ataraxia.

## Verification

CI checks the onboarding entry, all three pages, both mode choices, persistent revisit paths, the pre-completion disclosure and philosophy charter constraints. The complete Android build must still verify Java compilation, the non-debuggable APK, the package/version identity, the signature and the Internet-only manifest.

Phone testing must confirm:

1. A clean install opens page one rather than Home.
2. Back and Continue navigate without blank screens or clipped controls.
3. Each final mode button reaches Home and selects the expected mode.
4. Restarting does not force onboarding again.
5. Home and Settings can reopen the journey.
6. Reopening and changing mode does not reset usage counters or cooldown.
7. Text remains readable with large font and display scaling.
8. TalkBack reads headings, cards and buttons in a sensible order.
