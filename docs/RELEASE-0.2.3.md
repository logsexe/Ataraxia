# Still 0.2.3

An ad in the feed was being removed, then loaded again, which sent the scroll back to the top. Ads stay in the feed now, so you can scroll past them.

The feed switch is two sides: Friends and Influencers. Someone who follows you is a friend. Someone with 10,000 or more followers, or a verified account that does not follow you, is an influencer. If the page does not show enough to decide, that account stays on both sides. Open a profile to sort them from the header, or tap the other side if the sort is wrong. A celebrity mark from the previous build counts as an influencer.

Reels, Explore, Shop, and Live still do not open. The post counter is not applied.

## Installation

Download Still-0.2.3.apk and open it on Android 11 or newer. Uninstall the copy you have first. This build is signed with a new test key, so it cannot update the older one in place. Uninstalling clears the login stored in the app, not the Instagram account.

This CI build is signed with a test key and debugging is disabled. It is not a production signature.
